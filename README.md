# betterdiscord-assets

A small public mirror of the visual assets I use in my personal BetterDiscord setup — wallpapers, SVGs, GIFs, and theme CSS. Hosted here so I can reference them via stable raw GitHub URLs in CSS imports (`@import url(...)`) and `background-image` declarations.

This repo intentionally contains **only** the public-facing assets. Plugin source, build tooling, and internal notes live in a separate private workspace and are not published here.

## Contents

- **`themes/`** — BetterDiscord theme CSS files plus supporting images, SVGs, and animated backgrounds.
- **`assets/`** — Standalone image and SVG assets referenced from various configs.

## Usage

There is no install guide here — this is just a static asset host. If you want to use one of these images in your own BD theme or CSS snippet, link to the raw GitHub URL of the file directly:

```
https://raw.githubusercontent.com/matthewqilanthompson/betterdiscord-assets/main/<path-to-file>
```
